Como rodar:

1. Clone o repositório
2. Abra o projeto no terminal
3. Instale o Java 21 e o `mise` se necessário
4. Execute:
   ```bash
   mise install
   mise build
   mise test
   ```
5. Para iniciar a aplicação:
   ```bash
   ./gradlew.bat run
   ```
